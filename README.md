# AutoAE

## Automated Pharmacovigilance Case Analysis Tool

AutoAE is a prototype pharmacovigilance support application built with Python and Streamlit.

### Key Features

- Adverse Event extraction
- Suspected Drug identification
- Basic MedDRA PT and SOC mapping
- ICSR minimum-criteria screening
- Identifiable patient detection
- Identifiable reporter detection
- Automated case summary
- Basic seriousness screening
- Case analysis dashboard

### Workflow

ICSR Case Input
↓
Drug & Adverse Event Extraction
↓
MedDRA Mapping
↓
ICSR Validity Check
↓
Automated Case Summary

### Technology

- Python
- Streamlit
- Rule-based NLP / text processing
- MedDRA demonstration mapping

### Disclaimer

AutoAE is a prototype pharmacovigilance support tool. Drug/event extraction, MedDRA mapping and validity screening are rule-based demonstrations and should be reviewed by a qualified pharmacovigilance professional.
